# Decision records

Subset of the full `NumericCore` ADR set relevant to this Rust
workspace's own scope decisions (sparse format choice, decomposition
scope, LP/MILP/NLP sequencing, the UniFFI choice) plus 0008 (why this is
two repos at all) and 0010 (the automated release/FFI-sync pipeline
`release.yml` implements). The complete set, including Swift-API-shape
decisions (column-major layout, storage model, dispatcher concurrency),
lives in
[`Swift-NumericCore`](https://github.com/hakkabon/Swift-NumericCore)'s
`docs/decisions/`.
